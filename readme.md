This is the source code of our paper 'A Social Network-Assisted Knowledge Provision Approach for Green Semantic Communication'.

Our project is structured as follows:
- data_create.py create data based on Facebook dataset. Please run this file before main.py. If runs successfully, a file 'dict_data.txt' will be created under this folder.
- main.py contains the main procedure of our algorithm.
- tool.py contains the metric evaluation function, such as energy consumption, time delay in computing and communicaitons.
- policy.py includes our algorithm function and other comparison baselines.
